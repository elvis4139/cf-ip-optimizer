## 文档维护约定

1. 记录已确认决策时注明日期；尚未确认的参数明确标注为“待确认”。
2. 新结论优先追加新版本或新日期文档，不用旧文档中的历史参数覆盖最新决定。
3. 测试结果应注明测试条件、样本范围和统计口径，避免把局部样本推断为全量结果。
4. 文档不得把未执行的部署、测试、定时任务或发布写成已完成。
